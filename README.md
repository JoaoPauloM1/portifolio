## 🚀 Sobre o Projeto

Este projeto é um **Portfólio Online Pessoal**, desenvolvido utilizando o conceito de **Single Page Website** com navegação fluida por âncoras, layout responsivo e um visual moderno no estilo *Dark Tech*.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando:

* **HTML5 Semântico:** Estrutura limpa, hierárquica e acessível.
* **CSS3 Puro:** Variáveis nativas, Grid Layout, Flexbox e efeitos de vidro (*Glassmorphism*).
* **JavaScript Vanilla:** Manipulação do DOM nativa para interações e validação de formulários.
